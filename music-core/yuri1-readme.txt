YURI1 Music Core — Naming Standard (2026-10-09)

The Music site uses WWW canonical resource identities.

Core examples:
  post-20260928-02-o-cat-fighting-1.jpg
  post-20260928-02-o-cat-fighting-1.mp3
  post-20260928-02-o-cat-fighting-1.txt
  post-20260928-02-o-cat-fighting-1.html
  ip-album-icy-mini-vol1-10.jpg
  ip-no2-1.mp3
  yuri1-ip-story-1.txt

IDs must match codex-text stem from WWW exactly. Img numbers are preserved.
Catalog is music-core/index.html, public track pages are music-track/t-<id>-<img>.html.
On the WWW site story IDs remain PYYYYMMDD-NN even though storage files start post-.

Existing music-core MP3s are not bundled with this source package. Rename them using music-mp3-rename.csv or rename-mp3.py before publishing.

OC is a display name (e.g., C.Curo), while Theme identifies a local asset (e.g., c-curo.png).
